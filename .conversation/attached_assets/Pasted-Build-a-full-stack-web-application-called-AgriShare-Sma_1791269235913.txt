Build a full-stack web application called **AgriShare – Smart Agricultural Equipment Marketplace**.

### Project Goal
Create a modern platform where farmers can **BUY, SELL, and RENT agricultural equipment** such as tractors, harvesters, water pumps, seeders, sprayers, cultivators, and other farming machinery.

The application should be designed as a hackathon-ready MVP with a professional, modern, easy-to-use interface.

### Technology
Use:
- React
- Tailwind CSS
- Node.js + Express
- PostgreSQL database
- REST API
- Responsive design for desktop and mobile

If PostgreSQL is not immediately configured, create the application with realistic demo data first and structure the code so PostgreSQL can be connected easily.

   - Hero section:
     "The Smart Marketplace for Agricultural Equipment"
   - Search equipment
   - Buttons: Buy Equipment, Rent Equipment, Sell Equipment

   - Equipment name
   - Category

   - Manufacturing year
   - Usage hours

   - Location

5. **Rent Equipment**
   - Select equipment

6. **Smart Recommendation**
   Create a page called "Smart Equipment Finder".

   Ask the farmer:
   - What crop are you growing?
   - How many acres?
   - What work do you need to perform?
   - What is your budget?
   - Buy or Rent?

   Based on these inputs, recommend suitable equipment.

   Example:
   Farmer enters:
   Rice
   5 acres
   Harvesting
   ₹5,000
   Rent

   Show:
   "Recommended Equipment"
   Combine Harvester
   ₹4,500/day
   4.8 ⭐
   4.2 km away

   For the MVP, recommendation logic can use predefined rules/demo AI logic. Structure the code so an AI API can be added later.

7. **Dashboard**

10. **Ratings and Reviews**
   Farmers can rate equipment/owners.
   Show average rating and reviews on equipment details.

### Unique Hackathon Features

Include these features in the UI:

**1. Group Purchase**
Multiple farmers can show interest in jointly purchasing expensive machinery.

**2. Equipment Condition Verification**
For used equipment, show:
- Condition score
- Manufacturing year
- Usage hours
- Maintenance history

**3. Emergency Replacement**
If rented equipment breaks down, provide a button:
"Find Replacement Equipment"
and show nearby available equipment.

**4. Smart Price Estimation**
When an owner enters equipment type, age, condition and usage hours, suggest an estimated selling price.

**5. Trust Score**
Give equipment owners a trust score based on:
- Ratings
- Completed transactions
- On-time returns
- Verified profile
